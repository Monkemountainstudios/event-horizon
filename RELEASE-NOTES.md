# Event Horizon 0.9.14 — Public Test 1

This is the first public testing build of Event Horizon, an experimental instrument for playing with your own disappearing past.

The release includes continuous phrase capture, gravitational repetition and fragmentation, long-lived plasma churn, separate Hawking-radiation shimmer, collisions, Ghost memory, Retrograde, flybys, slingshots, and rare catastrophic rupture.

## Test priorities

- DAW scanning and insertion on Windows and macOS.
- Live capture with sustained, quiet, percussive, and phrase-based input.
- Project save/reopen and parameter recall.
- Automation of Gravity, Churn, Magnitude, and Mix.
- Long sessions at 44.1, 48, 88.2, and 96 kHz.
- Audio stability at 64–512 sample buffers.

The binaries are unsigned public-test builds. Please use GitHub Issues for repeatable technical problems.
